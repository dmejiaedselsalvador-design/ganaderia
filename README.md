# 🐂 Sistema de Gestión y Trazabilidad Ganadera

Sistema web desarrollado para la administración integral de operaciones pecuarias, optimización de engorda y control logístico de exportación de ganado en pie.

---

## 🚀 Características del Sistema

* **Control de Inventario Pecuario:** Seguimiento individualizado por identificador/arete, registro de características físicas, razas y trazabilidad de origen.
* **Módulo de Pesaje y Conversión:** Bitácoras periódicas para el cálculo de ganancia diaria de peso (GMD) y control de costos de alimentación asociados.
* **Gestión de Proveedores y Lotes:** Administración de compras, guías de traslado y lotes de adquisición.
* **Logística de Exportación:** Seguimiento de cumplimiento normativo y requisitos sanitarios para cruce fronterizo.
* **Control de Accesos por Roles:** Módulos protegidos para perfiles de administración, operación en báscula, comercialización y gerencia.
